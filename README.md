# My-Kinklist
My Kinklist is a simple, single-file checklist where you rate each item from 1 to 5, for yourself and for a partner. When you’re done, press Submit to get a code or link. Your partner pastes it into Compare to see your match percentage, a Yes list and a Let’s talk list. Everything runs in your browser. Your ratings stay on your device and nothing is uploaded or stored on a server. A code only contains your answers, so only share it with someone you trust.

18+ only.
